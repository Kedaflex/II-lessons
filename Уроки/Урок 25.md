## Ключевые понятия

* **API (Application Programming Interface):** Готовый набор способов, функций и протоколов, с помощью которых одна программа может взаимодействовать с другой программой или сервером.
* **HTTP-запрос (GET/POST):** Стандартизированный запрос клиента к серверу для получения (GET) или отправки (POST) данных.
* **JSON (JavaScript Object Notation):** Текстовый формат обмена данными в виде пар «ключ: значение», легко читаемый человеком и компьютером.
* **API Token:** Уникальный секретный ключ-пароль, идентифицирующий конкретного бота и предоставляющий доступ к управлению им через API.
* **Обработчик событий (Handler):** Функция в коде, которая вызывается автоматически при наступлении определенного события (например, при получении сообщения или нажатии кнопки).

### Этап 4. Изучение нового материала

**Преподаватель:** «Разберем архитектуру Telegram Bot API.

#### 1. Как работает Telegram Bot API?
Схема взаимодействия выглядит так:
`[Пользователь]` ➔ *(написал сообщение)* ➔ `[Сервер Telegram]` ➔ *(HTTP POST/JSON)* ➔ `[Ваш Python-скрипт]` ➔ *(ответная логика)* ➔ `[Сервер Telegram]` ➔ `[Пользователь]`.

Ваш скрипт постоянно спрашивает сервер Telegram: *"Есть ли новые сообщения?"* (Long Polling) или принимает их автоматически (Webhook).

#### 2. Формат JSON
Все данные передаются в формате **JSON** (JavaScript Object Notation). Это стандартный текстовый формат:
```json
{
  "ok": true,
  "result": {
    "message_id": 105,
    "from": {
      "id": 987654321,
      "first_name": "Иван"
    },
    "text": "Привет, бот!"
  }
}
```
В Python формат JSON автоматически превращается в обычный **словарь (dict)**!

#### 3. Шаг 1: Регистрация бота у @BotFather
Чтобы создать бота в Telegram:
1. Находим в Telegram официального бота `@BotFather`.
2. Отправляем команду `/newbot`.
3. Задаем имя и уникальный username бота (заканчивающийся на `bot`).
4. Получаем **API Token** — длинную строку вида `6123456789:AAHd8f3j...`.
   *ВАЖНО:* Токен — это секретный пароль! Если кто-то узнает ваш токен, он сможет управлять вашим ботом.

#### 4. Код базового бота на Python (библиотека pyTelegramBotAPI / telebot)
```python
import telebot

# Создаем экземпляр бота с вашим токеном
TOKEN = "ВАШ_СЕКРЕТНЫЙ_ТОКЕН"
bot = telebot.TeleBot(TOKEN)

# Обработчик команды /start
@bot.message_handler(commands=['start'])
def send_welcome(message):
    bot.reply_to(message, "Привет! Я твой первый бот на Python. Напиши мне что-нибудь!")

# Обработчик любого текста (Эхо-бот)
@bot.message_handler(func=lambda message: True)
def echo_all(message):
    user_text = message.text
    bot.reply_to(message, f"Вы сказали: {user_text}")

# Запуск постоянного опроса сервера
bot.polling(none_stop=True)
```»
