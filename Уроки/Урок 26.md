**Тема:** Интеграция LLM (API нейросетей) в телеграм-бота, понятие датасета, сбор, очистка, разметка (Annotation) и предобработка данных для обучения и дообучения моделей
**Класс:** 9
**Возраст:** 14–15 лет
**Продолжительность:** 45 минут
**Оборудование и материалы:** Компьютер преподавателя, проектор, интерактивная доска, ПК учащихся с Python 3.x, доступ к API больших языковых моделей (GigaChat API / YandexGPT API / OpenAI API или локальной модели) и табличному редактору (Excel / Google Таблицы / pandas).

## Цель урока

Сформировать у учащихся практические навыки интеграции искусственного интеллекта (LLM API) в пользовательские интерфейсы (телеграм-ботов) и системное понимание полного жизненного цикла подготовки качественных датасетов (сбор, фильтрация, очистка и разметка).

---

## Задачи урока

### Образовательные
* Изучить схему подключения LLM API к асинхронному телеграм-боту.
* Понять фундаментальное правило машинного обучения: **«Garbage In — Garbage Out»** (Мусор на входе — мусор на выходе).
* Изучить структуру **датасета (Dataset)**: признаки (Features), разметка (Labels), пропущенные значения (Missing Values), выбросы (Outliers).
* Освоить практический алгоритм очистки данных: удаление дубликатов, нормализация текста, обработка пропусков и создание системного датасета для дообучения/базы знаний бота.

### Развивающие
* Развивать критическое мышление и аналитические навыки при выявлении ошибок и предвзятостей (Bias) в исходных сырых данных.

### Воспитательные
* Воспитывать ответственность за качество данных и этику сбора персональной информации при формировании учебных датасетов.

## Ключевые понятия

* **Датасет (Dataset):** Упорядоченный и структурированный набор данных (таблица, коллекция текстов, файлов или изображений), предназначенный для обучения или тестирования моделей машинного обучения.
* **Признаки (Features):** Входные характеристики и параметры объектов в датасете (например, длина текста, ключевые слова, числовые показатели).
* **Разметка данных (Data Annotation / Labeling):** Процесс присвоения объектам датасета правильных меток или категорий (например, классификация писем на «Спам» / «Не спам»).
* **Очистка данных (Data Cleaning / Sanitization):** Этап предобработки, включающий удаление шума, дубликатов, нерелевантных символов и исправление пропущенных значений.
* **LLM Integration:** Связывание Bot API с нейросетевым API, при котором бот перенаправляет текст пользователя в нейросеть и возвращает сгенерированный с учетом контекста ответ.

## ПОДРОБНЫЙ СЦЕНАРИЙ ДЛЯ ПРЕПОДАВАТЕЛЯ

### Этап 1. Организационный момент

**Преподаватель:** «Здравствуйте, дорогие учащиеся! На прошлом уроке мы создали каркас телеграм-бота. Но пока наш бот умел только повторять наши же слова (эхо-режим). Сегодня мы сделаем настоящий прорыв: свяжем бота с интеллектуальным движком (LLM API) и научимся готовить качественные **датасеты** — топливо для любого машинного обучения!»

---

### Этап 2. Постановка проблемы

**Преподаватель:** «В индустрии машинного обучения есть известная поговорка: **"Garbage In — Garbage Out" (GIGO)** — *"Если на вход подать мусор, то и на выходе получится мусор"*.

Представьте: компания хочет создать бота-консультанта по расписанию школы. Разработчики скопировали данные с заброшенного сайта 5-летней давности, с опечатками, дубликатами и пустые строчками.

Что произойдет, когда ученик спросит такого бота: *"Во сколько завтра урок информатики?"*»

**Вопрос учащимся:** «Сможет ли самая дорогая и умная нейросеть в мире дать правильный ответ, если исходные данные ошибочны?»

**Ожидаемые ответы:**
* Нет, нейросеть поверит ошибочным данным и выдаст неправильный ответ или придумает несуществующий урок.

**Комментарий преподавателя:** «Совершенно верно! Модель не знает реального мира — она знает только тот датасет, который ей передали!»

---

### Этап 3. Актуализация знаний

**Преподаватель:** «Вспомним урок №25, где мы разбирали структуру JSON-запросов.»

**Вопрос учащимся:** «Как бот пересылает текст от пользователя в сервис нейросети?»

**Ожидаемые ответы:**
* Бот извлекает значение из поля `message.text`, формирует HTTP POST-запрос к API нейросети, получает JSON-ответ с текстом и отправляет его обратно пользователю.

**Комментарий преподавателя:** «Именно! Блок логики бота становится мостом между пользователем и LLM!»

### Этап 4. Изучение нового материала

**Преподаватель:** «Разберем, как устроена схема ИИ-бота и как подготавливать датасеты.

#### 1. Интеграция LLM API в Телеграм-бота
Вместо эхо-функции мы вызываем метод нейросети:
```python
@bot.message_handler(func=lambda m: True)
def handle_ai_dialog(message):
  user_query = message.text

  # Отправляем запрос в LLM API (например, GigaChat / YandexGPT / OpenAI)
  ai_response = ask_llm(
      prompt=user_query, system_prompt="Ты вежливый помощник школы №15"
  )

  # Отвечаем пользователю
  bot.reply_to(message, ai_response)
```

#### 2. Что такое датасет (Dataset)?
Для обучения или создания базы знаний (RAG / Fine-Tuning) данные организуются в виде таблиц:
- **Признак (Feature):** Вопрос пользователя, категории, ключевые слова.
- **Метка / Целевая переменная (Label):** Точный эталонный ответ.

#### 3. Этапы подготовки датасета
Подготовка данных занимает до 80% времени работы дата-сайентиста:
1. **Сбор (Data Collection):** Загрузка текстовых логов, таблиц, документов.
2. **Очистка (Data Cleaning):**
   - Удаление полных дубликатов.
   - Заполнение или удаление строк с пропущенными значениями (`NaN` / `Null`).
   - Удаление «мусорных» HTML-тегов, системных символов и опечаток.
3. **Нормализация (Normalization):** Приведение к единому регистру (нижний регистр), единому формату дат и номеров телефонов.
4. **Разметка (Data Annotation):** Назначение категорий (например, тема: `[Расписание]`, `[Питание]`, `[Экзамены]`).»

### Этап 5. Практическая работа

**Преподаватель:** «Перейдем к практическому заданию по очистке грязного датасета.»

#### Задание для практической работы

**Название:** «Очистка и разметка грязного датасета школьной базы знаний»
**Цель:** Научиться выявлять аномалии, удалять дубликаты, заполнять пропущенные значения и формировать валидный датасет в формате JSON/CSV для ИИ-бота.

##### Порядок выполнения:
1. Откройте предоставленную «сырую» таблицу с вопросами школьников (10 строк):
   - Строка 1: `"во сколько урок 1?"` | Ответ: `"В 8:30"` | Категория: `"Расписание"`
   - Строка 2: `"ВО СКОЛЬКО УРОК 1?"` | Ответ: `"В 8:30"` | Категория: `"Расписание"` *(Дубликат!)*
   - Строка 3: `"где столовая"` | Ответ: `NaN` | Категория: `NaN` *(Пропуск!)*
   - Строка 4: `"когда каникулы <br>"` | Ответ: `"С 25 октября"` | Категория: `"Каникулы"` *(HTML-тег!)*
   - Строка 5: `"ааааааааааааа"` | Ответ: `"Не знаю"` | Категория: `"Мусор"` *(Шум!)*
2. Проведите очистку:
   - Удалите дублирующую строку 2.
   - Заполните пропуск в строке 3 корректной информацией: Ответ: `"На 1 этаже"`, Категория: `"Столовая"`.
   - Очистите строку 4 от тега `<br>`.
   - Удалите «мусорную» строку 5.
3. Переведите очищенный датасет в формат валидного JSON-массива объектов.
