## Ключевые понятия

* **Задача регрессии (Regression Task):** Задача машинного обучения, в которой требуется предсказать непрерывное числовое значение (например, стоимость квартиры, температуру, балл на экзамене) на основе входных признаков.
* **Линейная регрессия (Linear Regression):** Алгоритм, моделирующий зависимость между переменными с помощью прямой линии (в случае 1 признака) или гиперплоскости (в случае множества признаков).
* **Веса модели ($w_1, w_0$ / Weights & Bias):** Числовые параметры алгоритма, регулирующие наклон линии регрессии и ее смещение.
* **Среднеквадратичная ошибка (MSE — Mean Squared Error):** Метрика качества, вычисляемая как среднее арифметическое квадратов разностей между предсказанными и реальными значениями:
  $$\text{MSE} = \frac{1}{n} \sum_{i=1}^{n} (y_i - \hat{y}_i)^2$$
* **Дерево решений (Decision Tree):** Алгоритм, принимающий решение путем последовательной проверки условий вида «Признак > Порог?».
* **Случайный лес (Random Forest):** Ансамблевый алгоритм, объединяющий предсказания множества независимых деревьев решений для повышения точности.

**Комментарий преподавателя:** «Именно! В машинном обучении эту формулу записывают так: $y = w_1 x + w_0$, где $w_1$ и $w_0$ называются **весами (Weights & Bias)**!»

### Этап 4. Изучение нового материала

**Преподаватель:** «Разберем, как машинное обучение находит наилучшую прямую линию.

#### 1. Уравнение Линейной Регрессии
Если у нас есть один признак $x$ (площадь), прогноз $\hat{y}$ (цена) вычисляется по формуле:
$$\hat{y} = w_1 \cdot x + w_0$$
- $x$ — признак (Feature).
- $\hat{y}$ — предсказанное значение (Target prediction).
- $w_1$ — вес признака (насколько сильно площадь влияет на цену).
- $w_0$ — базовая величина (сдвиг / bias).

#### 2. Как модель оценивает ошибку? Метрика MSE
Точки реальных данных почти никогда не лежат идеально на одной прямой.
Для каждой точки есть разница между реальным значением $y_i$ и предсказанным $\hat{y}_i$:
$$\text{Ошибка (Residual)} = y_i - \hat{y}_i$$

Чтобы отрицательные и положительные ошибки не гасили друг друга, их возводят в квадрат и берут среднее арифметическое. Это называется **Mean Squared Error (MSE)**:
$$\text{MSE} = \frac{(y_1 - \hat{y}_1)^2 + (y_2 - \hat{y}_2)^2 + \dots + (y_n - \hat{y}_n)^2}{n}$$

Цель алгоритма обучения — подобрать веса $w_1$ и $w_0$ так, чтобы **MSE была минимально возможной**!

#### 3. Другие модели машинного обучения
Линейная регрессия работает хорошо только тогда, когда зависимость действительно похожа на прямую. Но что делать, если зависимость сложная?
* **Дерево решений (Decision Tree):** Строит цепочку вопросов: *"Площадь > 40?"* ➔ если Да, *"Дом каменный?"* ➔ если Да, *"Цена = 12 млн"*.
* **Случайный лес (Random Forest):** Создает «совет» из 100 независимых деревьев решений. Каждое дерево голосует за свой вариант, а итоговый ответ определяется как среднее значение. Случайный лес — один из самых мощных алгоритмов в ML!»

## Ответы и решения для преподавателя

### Подробное решение практической работы (Этап 5):

#### Исходные данные:
- Точка 1: $(30, 6)$
- Точка 2: $(50, 9)$
- Точка 3: $(70, 13)$

#### 1. Модель А ($\hat{y} = 0.15 x + 1$):
- $\hat{y}_1 = 0.15 \cdot 30 + 1 = 5.5$ ➔ Ошибка: $(6 - 5.5)^2 = 0.25$
- $\hat{y}_2 = 0.15 \cdot 50 + 1 = 8.5$ ➔ Ошибка: $(9 - 8.5)^2 = 0.25$
- $\hat{y}_3 = 0.15 \cdot 70 + 1 = 11.5$ ➔ Ошибка: $(13 - 11.5)^2 = 2.25$
- $\text{MSE}_A = \frac{0.25 + 0.25 + 2.25}{3} = \frac{2.75}{3} \approx \mathbf{0.917}$

#### 2. Модель Б ($\hat{y} = 0.18 x + 0.3$):
- $\hat{y}_1 = 0.18 \cdot 30 + 0.3 = 5.7$ ➔ Ошибка: $(6 - 5.7)^2 = 0.09$
- $\hat{y}_2 = 0.18 \cdot 50 + 0.3 = 9.3$ ➔ Ошибка: $(9 - 9.3)^2 = 0.09$
- $\hat{y}_3 = 0.18 \cdot 70 + 0.3 = 12.9$ ➔ Ошибка: $(13 - 12.9)^2 = 0.01$
- $\text{MSE}_B = \frac{0.09 + 0.09 + 0.01}{3} = \frac{0.19}{3} \approx \mathbf{0.063}$

**Вывод:** Модель Б значительно точнее ($\text{MSE}_B = 0.063 < \text{MSE}_A = 0.917$).

### Ответы к этапу закрепления (Этап 7):
1. Модель №2 делает ошибку в среднем на $\sqrt{0.25} = 0.5$ млн рублей.
2. В квадрат разницу возводят для того, чтобы: а) исключить взаимное погашение положительных и отрицательных ошибок ($+2$ и $-2$), б) сильнее штрафовать модель за крупные отклонения.
