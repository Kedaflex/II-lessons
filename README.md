# 🤖 AI для 9-классников: Первые шаги в мир искусственного интеллекта

[![Python](https://img.shields.io/badge/Python-3.8%2B-blue)](https://www.python.org/)
[![Jupyter](https://img.shields.io/badge/Jupyter-Notebook-orange)](https://jupyter.org/)
[![License](https://img.shields.io/badge/License-MIT-green)](LICENSE)

Добро пожаловать! 👋

Этот репозиторий создан для учеников **9 классов**, которые хотят познакомиться с искусственным интеллектом (ИИ) и машинным обучением (ML) на практике. Здесь нет сложной университетской математики — только интересные задачи, простые объяснения и код на Python.

Мы научимся:
*   Понимать, как компьютеры «учатся» на данных.
*   Обучать простые нейронные сети.
*   Создавать свои первые умные приложения (чат-боты, распознавание картинок).

---

## 🎯 Для кого этот репозиторий?

*   **Ученикам 9 классов**, интересующимся технологиями.
*   **Учителям информатики**, ищущим готовые материалы для факультативов или кружков.
*   **Новичкам**, которые хотят начать путь в Data Science, но не знают, с чего начать.

**Требования:** Базовые знания информатики (понимание, что такое переменная и цикл). Знание Python — приветствуется, но мы разберем основы по ходу дела.

---

## 🛠 Что нужно для старта?

Все примеры в репозитории написаны на языке **Python**. Мы рекомендуем использовать **Google Colab** — это бесплатная среда, которая работает прямо в браузере и не требует установки программ на компьютер.

### Вариант 1: Облачный (Рекомендуемый)
1.  Зарегистрируйте аккаунт Google.
2.  Перейдите на [Google Colab](https://colab.research.google.com/).
3.  Откройте любой файл `.ipynb` из этого репозитория через меню «Файл -> Открыть блокнот -> GitHub» и вставьте ссылку на наш репозиторий.

### Вариант 2: Локальный (На компьютере)
Если вы хотите запускать код на своем компьютере, вам понадобится:
1.  Установить [Python](https://www.python.org/downloads/).
2.  Установить [Jupyter Notebook](https://jupyter.org/install) или среду разработки [VS Code](https://code.visualstudio.com/).
3.  Установить необходимые библиотеки (см. файл `requirements.txt`):
    ```bash
    pip install -r requirements.txt
    ```

## 🗺️ Структура курса

Мы будем двигаться от простого к сложному. Каждая папка — это отдельный урок или мини-проект.

| Модуль | Тема | Что узнаем? | Инструменты |
| :--- | :--- | :--- | :--- |
| **01** | Введение в ИИ | Что такое ИИ, ML и нейросети. Разница между ними. | Теория, примеры |
| **02** | Данные и Python | Как работать с таблицами данных, обрабатывать их и строить графики. | `Pandas`, `Matplotlib` |
| **03** | Первое предсказание | Линейная регрессия. Учим компьютер предсказывать цены и погоду. | `Scikit-learn` |
| **04** | Классификация | Как отличить кота от собаки? Логистическая регрессия и метод k-ближайших соседей. | `Scikit-learn` |
| **05** | Нейронные сети | Из чего состоит «мозг» робота. Создаем простую нейросеть с нуля. | `TensorFlow` / `Keras` |
| **06** | Компьютерное зрение | Распознавание рукописных цифр и эмоций на фото. | `OpenCV`, `Keras` |
| **07** | Обработка текста | Как чат-боты понимают наш язык. Простой анализ тональности текста. | `NLTK`, `Transformers` |

## 🚀 Пример проекта: Распознавание цифр

В папке `05_neural_networks` вас ждет тетрадка `mnist_digits.ipynb`. Там мы обучим нейросеть, которая сможет смотреть на картинку с рукописной цифрой и говорить, что это за цифра (от 0 до 9).

*Это выглядит как магия, но на самом деле — это математика и код, который вы сможете написать сами!*
